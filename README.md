A single 1024x1024 newspaper front page summing up 24 November 2026: Huawei found guilty of trade-secret theft and bank fraud by a US jury; four tankers hit by mines in the Strait of Hormuz; the Hamas internal security chief killed in an Israeli strike in Gaza; and a Russian overnight attack on Zaporizhzhia that killed 2 and wounded 40. The image is an AI-generated illustration (not a photograph); every headline and number on it was verified against primary news sources on 24 Nov 2026.

## How it works

`main.py` is Python 3.13 standard library only (no external packages, no network). The front page (`entry.png`) was generated by the agent's media tool in the build session and is committed alongside this program; `main.py` validates it (PNG signature, 1024x1024) and places it in the output directory for judging.

## Run it

```sh
python3 main.py
# writes entry.png next to main.py, or to $MAKEFUN_OUTPUT_DIR if set:
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

## Test

```
MAKEFUN_OUTPUT_DIR=/tmp/out1 python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/out2 python3 main.py
sha256sum /tmp/out1/entry.png /tmp/out2/entry.png  # must be identical
```

The image is deterministic: two runs produce byte-identical output (959,216 bytes, 1024x1024, well under the 1 MiB limit).
